# 专题四：利率地心引力模型与内在价值两阶段折现全集

> 本专题基于 1999 年太阳谷演讲、2001 年《财富》专访与威廉姆斯投资价值理论深度蒸馏。

---

## 一、 现行利率是资产定价的地心引力（Interest Rate Gravity, 1999）

巴菲特在 1999 年太阳谷演讲中确立了利率与资产估值的数学关系：
> “利率之于资产定价，就像地心引力之于物理世界。利率上升时，所有资产（股票、房地产、债券）的估值中枢都必须向下调整；当利率处于极低水平时，资产估值就会飞向天空。”

### 股权风险溢价 (ERP) 判定矩阵：
$$\\text{股票所有者收益率 (Earnings Yield)} = \\frac{\\text{基准所有者收益}}{\\text{当前总市值}}$$
$$\\text{股权风险溢价 (ERP)} = \\text{股票所有者收益率} - \\text{现行 10 年期国债收益率}$$

| ERP 水平 | 地心引力状态 | 投资决策定调 |
| :--- | :--- | :--- |
| **ERP ≥ +4.0%** | 超强重力吸引区（收益率显著超越国债） | **巴菲特极度贪婪买入区**（如 2016 苹果、1988 可口可乐） |
| **+1.0% ≤ ERP < +4.0%** | 合理引力区（提供适度风险补偿） | 估值合理，需顶级护城河支持 |
| **-1.0% ≤ ERP < +1.0%** | 引力平衡点（与无风险国债回报相仿） | 风险收益比平庸，缺乏吸引力 |
| **ERP < -1.0%** | 严重引力倒挂（股票回报率低于国债） | **高估/泡沫危险区**（如 1999 互联网泡沫、2024 高估值科技股） |

## 二、 内在价值两阶段折现模型（Two-Stage DCF）

$$\\text{Intrinsic Value} = \\sum_{t=1}^{5} \\frac{\\text{OE}_0 \\times (1+g_1)^t}{(1+r)^t} + \\sum_{t=6}^{10} \\frac{\\text{OE}_5 \\times (1+g_2)^{t-5}}{(1+r)^t} + \\frac{\\text{OE}_{10} \\times \\text{Multiple}}{(1+r)^{10}}$$

- **前 5 年增速 $g_1$**：取历史中枢的 70%~80%（通常保守设定为 4%~8%）；
- **6~10 年过渡增速 $g_2$**：锚定 GDP 长期增速（2.5%~3.5%）；
- **折现率 $r$**：取 $\\max(\\text{国债利率} + 4.0\\%, 9.0\\% \\sim 10.0\\%)$；
- **第 10 年末残值倍数**：保守取 10x ~ 16x 所有者收益；
- **安全边际（Margin of Safety）买入线**：
  - **7 折买入线 (30% Margin)**：常规优质股观察线；
  - **6 折绝对买入线 (40% Margin)**：巴菲特严苛重仓线；
  - **5 折烟蒂买入线 (50% Margin)**：格雷厄姆深度价值线。

## 三、DCF 增速假设的宏观锚定框架（v8.0 新增）

巴菲特在 1994 年致股东信中指出："任何试图用精确数字描述未来的人都是在愚弄自己。"  
合理的增速假设必须锚定可验证的宏观经济数据，而非凭空乐观预测。

### 1. 宏观增速参考锚点（2024-2026年）

| 参考指标 | 数值 | 用途 |
| :--- | :--- | :--- |
| 中国名义 GDP 增速 | 约 4.5%~5.5% | g1（中国企业）上限参考 |
| 中国实际 GDP 增速 | 约 4.0%~5.0% | g1 中枢参考 |
| 美国名义 GDP 增速 | 约 3.5%~4.5% | g1（美股企业）上限参考 |
| 全球实际 GDP 增速 | 约 2.5%~3.0% | g2（永续增速）锚点 |
| 全球通胀中枢 | 约 2.0%~2.5% | g2 最低下限参考 |

### 2. g1（前5年增速）设定决策树

```
g1 上限铁律：不得超过所在市场名义 GDP 增速的 1.5 倍

例外情形（允许超过 GDP 的 1.5 倍 g1 的条件）：
  ✓ 企业当前市占率 < 5%（仍处于快速渗透期）
  ✓ 行业总体规模仍处于高速扩张初期（如智能汽车、生成式AI基础设施）
  ✓ 且必须在报告中明确论证超额增长的可持续性来源（非臆测）

保守原则（巴菲特偏好）：
  g1 = 历史5年复合增速 × 0.7（取历史中枢的七成，给不确定性留余量）
```

### 3. g2（6-10年永续增速）设定铁律

```
g2 绝不能超过全球实际 GDP 增速 + 1%（约 3.5%~4.0%）

原因：长期来看，任何一家企业的增速不可能长期超过整体经济增速，
否则该企业最终将大于整个全球经济——这在数学上是荒谬的。
（参考：巴菲特 1999 年太阳谷演讲对 1960 年代 Nifty Fifty 泡沫的批判）

建议 g2 设定：
  成熟优质企业：2.0%~3.0%
  保险/银行（慢速行业）：1.5%~2.5%
  中国本土消费企业：2.5%~3.5%
```

### 4. 折现率（r）设定规则

```
r = max(无风险利率 + 风险溢价, 最低折现率下限)

风险溢价参考：
  顶级护城河企业（如茅台、可口可乐）：+3.5%
  优秀企业（宽护城河）：+4.0%~4.5%
  普通企业：+5.0%~6.0%

最低折现率下限：
  非金融企业：8.0%~9.0%
  保险/银行（业务稳定性高）：7.5%~8.0%

注意：当无风险利率极低时（如中国国债 2.0%），
不应让折现率也相应降低至 5%~6%——这会使几乎任何资产都显得"合理"，
应保持折现率不低于 8% 以防止估值泡沫化。
```
