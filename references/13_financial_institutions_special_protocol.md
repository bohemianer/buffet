# 专题十三：金融机构特殊分析协议（Financial Institutions Special Protocol）

> 适用范围：保险公司、银行、证券、资产管理、金融控股集团（如中国平安、中国人寿、平安银行、招商银行、中国人保等）
> 本专题系统说明为何通用分析框架对金融机构不适用，以及应采用的正确替代指标体系。

---

## ⚠️ 核心警告：通用 OE 公式对金融机构无效

### 错误应用通用公式的致命误区

**通用所有者收益公式（仅适用于非金融企业）：**
```
所有者收益 = GAAP净利润 + 折旧摊销 - 维持性CapEx
```

**对金融机构的三大误导：**

1. **CapEx 与利润规模完全不成比例**：平安年均 CapEx 约 80 亿元，但净利润超 1,300 亿元。直接套用会得出"含金量 105%"的虚假高含金量结论，实际上 80 亿 CapEx 对平安这种以投资为核心的金融集团毫无意义。

2. **"维持性支出"定义完全不同**：金融机构的核心维持性支出是**信用减值拨备（Credit Provision）**，而非物理资产折旧。平安每年计提的贷款损失准备金超过 650 亿元——这才是其真正的"维持性隐性成本"。

3. **折旧摊销是有意义的真实成本**：保险公司的折旧摊销中包含大量寿险合同成本摊销（VOBA/DAC），这些不应简单加回。

## 一、保险公司专属分析框架

### 1. 核心利润指标：营运利润（Operating Profit）

保险公司应以**管理层披露的营运利润（Operating Profit）**替代 GAAP 净利润作为基准盈利：

```
营运利润 = GAAP净利润
         - 短期投资波动（浮盈/浮亏）
         - 折现率变动对准备金的影响
         - 一次性非日常损益
```

**为什么必须用营运利润？**
- 保险公司持有大量权益类资产（股票、基金），资本市场波动导致 GAAP 净利润每年可能剧烈波动 ±30%~50%，严重干扰对其真实经营能力的判断。
- 中国平安、中国人寿均披露营运利润指标，且国际主流分析机构（高盛、摩根士丹利）均采用此口径。

### 2. 承保端三大核心指标

| 指标 | 计算方式 | 健康标准 | 含义 |
| :--- | :--- | :--- | :--- |
| **综合成本率（Combined Ratio）** | 赔付率 + 费用率 | < 100%（越低越好） | <100% 意味着承保端产生利润，浮存金成本为负 |
| **承保利润（Underwriting Profit）** | 保费收入 - 赔付 - 费用 | 正值 | 直接衡量承保业务是否盈利 |
| **浮存金成本（Float Cost）** | 承保亏损 / 平均浮存金 | < 国债利率（中国约2.5%以下） | 负值为最优，代表"有人付钱让公司投资" |

### 3. 浮存金经济价值测算（Float Economics）

```
浮存金经济价值贡献 = 平均浮存金规模 × (目标投资回报率 - 浮存金成本)
```

**实战示例（中国平安财险）：**
- 平均浮存金规模（责任准备金）≈ 4,000 亿元
- 目标综合投资回报率 ≈ 5.5%
- 综合成本率约 98% → 浮存金成本约 2%
- 浮存金经济贡献 ≈ 4,000 × (5.5% - 2%) = **140 亿元**
- 这部分价值在 GAAP 报表中并未单独体现，但是平安投资收益的核心来源之一。

### 4. 寿险内含价值（Embedded Value，EV）分析

对于寿险业务，传统 PE/PB 估值失真严重，应使用**内含价值（EV）**体系：

| 指标 | 定义 | 中国平安参考值 |
| :--- | :--- | :--- |
| **调整后净资产** | 剔除无效资产后的有效净资产 | 约 4,500 亿元（2024年） |
| **有效业务价值（VIF）** | 现有保单组合未来利润现值 | 约 6,800 亿元（2024年） |
| **集团内含价值（Group EV）** | 调整净资产 + VIF | 约 1.4 万亿元（2024年） |
| **一年新业务价值（NBV）** | 当年新增保单未来利润现值 | 约 400 亿元（2024年） |
| **P/EV 比率** | 市值 / 集团 EV | 0.7x 以下为低估 |

**巴菲特对保险公司估值的核心原则（来自 GEICO 案例）：**
"对于保险公司，我们不关注当期利润，我们关注：(1) 浮存金规模是否持续增长；(2) 浮存金成本是否低于无风险利率；(3) 管理层是否具备长期承保纪律。具备这三点的保险公司是真正的现金复利机器。"

## 二、银行专属分析框架

### 1. 银行核心盈利指标

| 指标 | 计算方式 | 健康标准 | 含义 |
| :--- | :--- | :--- | :--- |
| **净息差（NIM）** | 净利息收入 / 平均生息资产 | 中国银行业 1.5%~2.0%+ | 银行核心盈利能力，利差收入来源 |
| **不良贷款率（NPL Ratio）** | 不良贷款余额 / 贷款总额 | < 1.5% 为优秀 | 资产质量核心指标 |
| **拨备覆盖率** | 贷款损失准备 / 不良贷款 | > 200% 为充足 | 抵御未来损失的缓冲垫 |
| **核心一级资本充足率（CET1）** | 核心一级资本 / 风险加权资产 | > 12% 为充裕 | 监管合规与抗风险能力 |
| **PPOP（拨备前营业利润）** | 营业利润 + 信用减值损失 | 越高越好 | 核心真实盈利能力（排除拨备周期影响） |

### 2. 银行的"所有者收益"等效指标

**银行版所有者收益（等效概念）：**
```
银行所有者收益等效值 = 拨备前营业利润（PPOP）
                     - 正常化信用损失（Normalized Credit Cost）
                     - 维持资本充足率所需的留存利润
```

注意：**不要直接使用**银行的 GAAP 净利润进行 OE 计算，因为银行的拨备在经济周期中差异巨大，可能导致利润严重失真。

## 三、金融控股集团（如中国平安）的综合估值

对于综合金融集团，应采用**分部加总估值法（Sum-of-Parts, SOTP）**：

| 业务板块 | 适用估值方法 | 估值锚点 |
| :--- | :--- | :--- |
| 寿险 + 健康险 | P/EV | P/EV 0.7x ~ 1.0x（合理区间） |
| 财产险 | P/B | P/B 1.0x ~ 1.5x（综合成本率<100%时） |
| 银行（平安银行） | P/B | P/B 0.6x ~ 1.0x（当前中国银行业估值中枢） |
| 资产管理 | P/E | P/E 10x ~ 15x |
| 科技/养老生态 | P/Sales 或战略价值折扣 | 适当折价反映不确定性 |

## 四、金融机构 ROE 的正确读法

### 1. 必须使用"营运利润 ROE"而非 GAAP ROE

对于保险公司：
```
营运利润 ROE = 营运利润（归母）/ 年初归母净资产
```

对于银行：
```
实质 ROE ≈ PPOP 法 ROE（更能反映真实经营能力，排除拨备波动）
```

### 2. 杠杆率的正确理解

金融机构高杠杆（保险公司杠杆约 8~10x，银行约 12~15x）是其商业模式的内在特征，**不能简单套用工业企业的"低负债比率"要求**。

真正需要关注的金融杠杆风险指标：
- 保险公司：综合偿付能力充足率（核心 > 100%，综合 > 200%）
- 银行：资本充足率（CET1 > 12%）、流动覆盖率（LCR > 100%）

## 五、金融机构芒格逆向测试专属清单

以下是金融机构特有的致命风险，必须在逆向测试中优先排查：

1. **利差损风险**：长期低利率导致负债端预定利率刚性，而资产端实际收益率持续下滑。检验：新产品预定利率是否已下调至 2.5% 以下？
2. **投资端黑天鹅**：大量持有非标资产（房地产信托、地方城投非标债）的减值风险。检验：非标资产占投资总资产比例是否超过 10%？
3. **准备金精算假设风险**：若折现率假设过于乐观，未来需大幅补提准备金，冲击利润。检验：准备金折现率与市场长期利率是否一致？
4. **代理人渠道崩塌风险**：代理人数量大幅萎缩导致新业务价值断崖。检验：代理人规模年化降幅是否超过 15%？
5. **系统性监管政策风险**：保险行业预定利率管制、银行资本充足率监管趋严等。
6. **再保险对手方风险**：大比例转分保的再保险合约对手方的偿付能力。

## 六、快速判断表：何时启用本协议？

> 当分析标的符合以下任一条件时，必须放弃通用 OE 公式，切换至本协议：

| 触发条件 | 示例 |
| :--- | :--- |
| 主营业务包含保险（寿险/财险/健康险） | 中国平安、中国人寿、中国人保、新华保险 |
| 主营业务为银行存贷款 | 招商银行、平安银行、建设银行 |
| 主营业务为证券/资产管理 | 中信证券、华泰证券、东方证券 |
| 金融资产占总资产比重 > 60% | 综合金融控股集团 |
| 公司持有保险牌照/银行牌照 | 所有持牌金融机构 |
